# ABC Bağlamaca

Numberlink bulmaca oyunu. `main` dalında kök `index.html` olarak bulunuyordu; MiniBilge OS ile birleştirme sonrası buraya taşındı.

## Çalıştırma

```bash
# Proje kökünden
python3 -m http.server 3000
# Tarayıcı: http://localhost:3000/games/abc-baglamaca/
```

Veya bu klasörde doğrudan `index.html` dosyasını açın.
